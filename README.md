# 🧠 Brainrot AutoJoiner API

API hosteada en Render + GitHub para Brainrot AutoJoiner.

## Endpoints:
- `GET /` - Página principal
- `GET /api/jobs` - Obtener todos los jobs (para Roblox)
- `POST /api/jobs` - Agregar nuevo job (para bot Discord)
- `GET /status` - Estado del servidor
